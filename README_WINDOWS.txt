RICO FIELDOPS - WINDOWS
=======================

FIRST-TIME START
1. Right-click the downloaded ZIP > Properties.
2. Check Unblock if Windows shows that option, then Apply.
3. Extract the ZIP completely.
4. Open the extracted fieldops_v3 folder.
5. Double-click START_WINDOWS.bat.
6. Keep the black window open while using FieldOps.

FIRST LOGIN
Email: admin@local
Password: admin123

After signing in, go to Team & Assets to add your permanent users and Settings to change your password.

IF YOU ALREADY USED THE PREVIOUS VERSION
Read UPGRADE_FROM_V2.txt before launching this release. Copy your old fieldops.db and uploads folder into this release first so your existing records carry forward.

WINDOWS SMART APP CONTROL
If Windows blocks START_WINDOWS.bat because it came from the internet, do not disable Smart App Control. Close the message, right-click the original ZIP > Properties > Unblock > Apply, delete the already-extracted folder, and extract the ZIP again.

BACKUPS
Use Settings > Download Full Backup regularly. The backup includes the database and uploaded job files.
